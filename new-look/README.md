# New look (preview)

A second design for raavanaa.org, kept in its own folder so the current site is untouched.
Open it at /new-look/ on the draft preview.

- Pages: index (home), initiatives, projects, project (/new-look/projects/<slug>), impact,
  get-involved, sponsor, request, about.
- assets/app.js draws the header, footer, banners, the Initiate → Activate → Impact circle and the
  project cards. Project data comes live from the site's own /projects.json, pictures from /img.
- Forms are Netlify forms named new-look-volunteer, new-look-partner, new-look-sponsor-a-smile,
  new-look-request-a-smile.
- Fonts (Kaushan Script, Poppins) are kept in assets/fonts under the Open Font License.
- Still a preview: leave this folder out of "post" unless it is meant to go live.
