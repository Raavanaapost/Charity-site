# Charity site

Project stories site, hosted on Netlify.

- **Edit content:** go to `/admin` on the live site and sign in with GitHub.
- `content/projects.json` – all projects (edited from the admin page)
- `content/site.json` – site name, home page text, About page
- `images/uploads/` – photos added from the admin page
- `index.html`, `project.html`, `about.html`, `css/`, `js/` – design and layout
